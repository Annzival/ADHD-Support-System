# 干预策略冲突不自动改变执行安排或联系权限

当执行安排所需的准备提示、开始干预或会话检查点落在干预策略禁止联系的时间或渠道内时，确定性规则记录干预策略冲突。冲突只表示系统不能按原安排主动联系，不表示下一步行动不可执行，也不自动改期。

系统在启用或修改用户方案、修改执行安排以及修改干预策略时检测冲突，并在主窗口显示非模态冲突卡片，不等到计划开始时才提示。卡片说明受影响的执行安排、无法送达的干预以及行动仍可由用户主动执行这一事实。

## 用户选择

冲突卡片提供三个平等选择：

1. 保留执行时间，并接受该时段没有主动干预；
2. 将执行安排改到允许联系的时段；
3. 由用户主动修改干预策略。

系统不得默认推荐扩大允许联系的时段，也不得因截止日期或任务紧迫性绕过安静时段。用户选择改期后，Agent 可以提出最多三个符合当前约束的时间候选；用户选择修改干预策略时，应用进入确定性设置界面，Agent 不直接修改联系权限。

用户暂不处理时可以保存执行安排，但界面必须清楚标明该时段没有主动干预，系统不为同一冲突反复发送气泡或通知。冲突解决或相关安排、策略发生变化后，旧建议标记为已被取代。模型不可用时，冲突说明和三个确定性选择仍然可用。
