# 剩余精力建议保留平等的结束选择

用户在收尾确认中报告还有精力后，应用在当前上下文显示一张剩余精力建议卡片，不再发送气泡、系统通知或邮件。如果系统不知道用户当前可用时间或精力范围，最多要求一次简短选择，候选包括约五分钟、约十五分钟、三十分钟以上和不确定。

“到此结束”始终作为与继续工作平等的选择，系统不得把继续工作默认解释为更成功，也不得把没有使用的剩余精力记为浪费或失败。用户选择到此结束或关闭建议后，系统停止追问。

## 候选边界

Agent 只能从已确认用户方案中选择最多三个继续候选，不得借此制定新的学习或求职策略。候选优先来自当前工作所需的短小收尾、能降低下次启动成本的准备行动，以及依赖已经满足且适合前置的后续行动。每项候选显示预计用时、简短推荐理由，以及它将替代或前置的原执行安排；Agent 可以标出一个推荐项，但不得自动增加工作或延长用户允许的工作时段。

建议在当前可用时间结束、下一个已确认安排开始或相关用户方案状态变化时过期。用户选择继续候选后，确定性变更确认界面核对对当天执行安排的影响，确认后才创建新的执行安排。
