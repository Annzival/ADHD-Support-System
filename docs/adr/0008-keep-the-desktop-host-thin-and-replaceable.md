# 保持桌面宿主轻薄且可替换

桌面宿主是可替换的操作系统适配层，不是第二套后端。只有在技术验证原型确认托盘常驻、置顶小窗、开机启动、可交互系统通知和 Python 进程守护均可行后，才正式采用 Wails v3；验证失败时可以替换 Wails，而无须修改智能体核心或桌面客户端。

## 职责

1. 启动并检查 Python 智能体核心，在必要时重启该进程。
2. 提供单实例约束、系统托盘常驻、开机启动和可交互的原生系统通知。
3. 提供显示当前下一步行动和“立即开始”操作的置顶小窗。
4. 管理本地端口、临时认证令牌和桌面集成日志。

## 排除的职责

桌面宿主和桌面客户端不直接访问 SQLite，不持久化权威领域状态，不判断任务调度或干预规则，也不调用 LLM。这些职责全部保留在智能体核心边界内。
