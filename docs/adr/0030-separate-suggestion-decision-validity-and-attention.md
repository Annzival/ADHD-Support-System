# 分离智能体建议的决定、有效性和注意状态

每项智能体建议分别记录用户决定、业务有效性和注意状态，不使用一个含义混杂的状态字段推断其他维度。

## 三个维度

- 决定状态包括待决定、已接受、修改后接受和不采用。不采用时不要求用户说明原因，但可以自愿提供反馈。
- 有效性状态包括有效、已过期和已被取代。只有建议实际依赖的状态发生变化，或出现针对同一目标的更新建议时，才会使原建议失效；无关状态变化不得让建议集体过期。
- 注意状态包括未查看和已查看，并可以附加一个可选的稍后处理时间。关闭气泡只把建议标记为已查看，不等于不采用；界面不使用红点数量制造建议积压感。

## 稍后处理

用户选择具体恢复时间后，系统可以在该时间进行至多一次低强度提示，并继续受干预策略约束。用户没有选择时间时，建议只保留在主界面的被动入口中，不主动再次提示。等待期间已经过期或被取代的建议不再恢复提示。

## 应用结果

修改后接受时，系统同时保留原始建议和最终应用版本，以便审查 Agent 建议与用户修改之间的差异。确定性领域命令应用失败时，建议不能进入已接受状态；系统说明冲突，并允许用户重新查看或生成新建议。
