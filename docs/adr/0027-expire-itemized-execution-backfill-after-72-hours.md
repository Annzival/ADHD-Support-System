# 逐项执行补记保留 72 小时后降低为期间级核对

执行窗口结束后，执行补记入口被动保留 72 小时，不发送通知，也不显示红点或未读数字。同一天存在多个未确认行动时，系统将它们合并到一个“补记当天执行结果”入口，避免生成不断增长的逐项债务列表。用户可以逐项补记，也可以选择记不清或跳过核对。

日终复盘可以呈现当天尚未确认的行动并让用户补充执行事实，但完成日终复盘不能自动把这些行动判定为未执行，也不能在没有用户确认的情况下消除其未知状态。

## 过期

72 小时后，系统关闭逐项执行补记入口，保留原始干预记录和未确认执行状态，不把缺失信息记为失败。用户数天后回来时，ADR-0017 定义的重新进入流程可以通过期间执行核对概括确认这段时间的执行情况，但不得要求用户逐项追溯每个行动。期间执行核对允许跳过；无法回忆的事实继续保持未知。
