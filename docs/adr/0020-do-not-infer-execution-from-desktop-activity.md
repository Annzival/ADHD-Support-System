# v0.1 不通过桌面活动推断执行状态

v0.1 的主动干预只依据用户确认的执行安排、用户在应用中的明确操作或状态报告，以及智能体核心已经记录的任务、执行会话和干预状态。系统不采集或使用前台窗口及其标题、键盘和鼠标活动、浏览器历史、进程列表、截图或屏幕内容来判断用户是否开始或正在执行任务；沉默也不能与这些信号组合后变成执行结论。

## 设备可用性

系统可以读取睡眠、唤醒和锁屏等设备可用性信号，但只能用于判断干预能否送达以及是否需要进入恢复流程，不能据此判断用户是否工作。

## 演进边界

ActivityWatch 等本地活动数据以后只能作为用户明确启用的独立扩展进行评估，不得默认开启，也不得让推断结果覆盖用户报告。
