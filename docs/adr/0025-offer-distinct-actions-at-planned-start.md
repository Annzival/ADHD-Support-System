# 计划开始时提供状态明确的可操作干预

下一步行动到达计划开始时间，且系统没有记录它已经开始、完成或改期时，触发一次开始干预。开始干预不先询问用户为什么没有开始，也不因送达而自动启动计时或执行会话。

## 操作

开始干预提供以下相互区分的操作：

- “立即开始”：从当前时间建立执行会话。
- “我已经开始”：校正为执行中；它是独立操作，不能与完成状态合并。
- “我已经完成”：校正为已完成，并进入 ADR-0023 定义的可跳过收尾确认；它是独立操作，不能与开始状态合并。
- “现在有点难开始”：先提供缩小下一步行动或处理当前阻碍的支持，不要求用户先解释完整原因。
- “改到具体时间”：由用户确认新的执行时间，结束本次开始干预。
- “今天不做”：记录用户对本次执行安排的决定，并评估它对用户方案的影响；系统可以提出方案调整建议，但不得擅自改写用户方案。

用户没有回应时，状态保持未知，并沿用 ADR-0016 规定的至多一次低强度跟进后停止规则。
