# 停止主动跟进后保留未决开始界面至执行窗口结束

开始干预送达后，系统按照用户设置的开始宽限时间等待明确回应；界面可以建议 10 分钟，但不把该数值宣称为最优间隔。宽限时间结束后，用户仍未对这次开始干预作出任何明确回应时，系统最多进行一次显著程度低于首次干预的跟进。行动已经开始、完成或改期时取消跟进；跟进时间落入安静时段、PC 离线，或下一项计划工作已经开始时，跟进直接失效，不延迟补发。

第二次仍无回应后，系统停止对此次执行安排的主动联系，但不立即移除 ADR-0025 定义的操作。完整操作集以未决开始界面的形式被动保留，不再弹出、闪烁、产生红点或触发其他显著性变化；静态保留不算一次新的干预。

## 保留期限

未决开始界面按照以下优先顺序确定结束时间：

1. 用户设置了明确执行窗口时，以该窗口的结束时间为准。
2. 没有明确执行窗口但设置了预计时长时，以计划开始时间加预计时长推导结束时间。
3. 两者都没有设置时，以用户本地时区的次日 00:00 为结束时间。

同时存在明确执行窗口和预计时长时，明确执行窗口决定界面的保留期限，预计时长继续用于执行会话的检查点。如果保留期限早于宽限时间结束，界面按期转换且不再进行跟进。下一项计划工作开始后，未决开始界面是否仍显示在置顶小窗由后续呈现规则决定，但它应继续作为主界面的被动入口保留到上述结束时间。

## 转换为执行补记

保留期限结束后，系统关闭原有操作界面并提供执行补记入口。补记使用历史状态措辞，包括已经完成、开始过且仍在执行、执行过但没有完成、没有开始和已经改期；不得继续用“立即开始”或含义不明确的“我已经开始”核对过去的执行情况。未补记仍只表示系统缺少执行证据，不得记为失败。
