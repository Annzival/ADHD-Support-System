# 持久记录建议变更并按依赖安全撤销

用户接受或修改后接受智能体建议时，系统保存建议应用记录，包含来源建议、变更前状态、最终应用内容、变更后状态、应用时间和确定性领域命令结果。应用成功后，当前界面显示非模态结果提示并提供撤销；同一操作持续存在于对应用户方案或当天执行安排的变更历史中，不使用只在数秒内有效的临时撤销入口。

如果应用后没有产生依赖该变更的新执行安排、执行会话或其他修改，系统允许通过确定性领域命令直接撤销。如果后续状态已经依赖该变更，系统不得直接回滚并破坏依赖；界面显示受影响内容，并提供手动调整或生成补偿性调整候选的入口。补偿性调整会修改用户方案或当天安排时，仍需经过变更确认。

撤销不会删除历史记录，来源建议、应用结果和撤销结果都继续保留。撤销本身不依赖 LLM；只有存在后续依赖、需要构造补偿性调整时，才可以请求 Agent 生成候选。

用户报告的执行事实不使用撤销语义。误报完成、实际用时或其他执行结果时，通过更正执行事实保存新的事实版本，而不是回滚历史。建议已经过期或被取代后不能重新接受，但此前已经应用的变更仍可从变更历史判断能否安全撤销。
