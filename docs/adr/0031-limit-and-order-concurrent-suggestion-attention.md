# 限制并确定性排序并存建议的注意请求

同一目标、同一建议目的在同一时刻只保留一项有效建议。新建议完成结构校验后取代旧建议，旧记录继续用于审计，但不再请求用户处理。不同上下文中的建议保持独立，不能把具有不同证据、有效期或修改权限的建议合并成一项含义模糊的建议；界面可以按上下文分组呈现。

## 单一注意请求

同一时刻最多只有一项智能体建议可以通过气泡、对话入口或外部通知主动请求用户注意。其他有效建议只在主界面的对应上下文中被动保留。用户处理、不采用或延后当前建议后，系统不立即连续弹出下一项建议；其他建议等到用户进入对应上下文或下一个自然交互边界再呈现。

## 确定性优先级

智能体核心按照以下顺序确定哪项建议可以请求注意：

1. 用户刚刚主动请求，或当前流程继续前必须处理的建议；
2. 即将失效且与当前执行直接相关的建议；
3. 影响今天已经确认执行安排的建议；
4. 可以延后的用户方案优化和复盘建议。

LLM 可以提供影响信息，但不能自行声明最高优先级。已经过期或被取代的建议不再请求注意，不进入待处理入口，也不计入未读数量。
