# 原子保存权威当前状态和领域事件，不采用完整事件溯源

首个 MVP 以 SQLite 中的当前领域记录作为直接读取的权威状态，而不依靠重放全部历史事件重建状态。用户命令和确定性规则转换携带唯一命令 ID、目标对象 ID 与预期状态版本；智能体核心在同一事务中校验版本、更新权威当前状态、追加不可回写的已发生事实领域事件，并保存命令处理结果和必要调度记录。相同命令 ID 的重试返回第一次结果，不重复转换；非法或过期命令不产生成功事件，只可保留诊断或审计信息。重启后从当前状态恢复有效调度；领域事件用于历史追溯、可验证指标和未来集成，不是唯一状态源，LLM 输出及模型会话也不能直接成为领域事件。
