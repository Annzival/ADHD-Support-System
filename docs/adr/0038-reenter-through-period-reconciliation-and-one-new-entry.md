# 重新进入流程只建立一个当前执行入口

用户主动返回应用后，主窗口打开重新进入流程，不自动弹出模态框，也不逐条重放错过的提醒。本机应用内气泡或系统通知可以直接定位到该流程。

## 期间事实核对

流程先显示已知的最后执行状态和恢复包、用户已经确认的期间执行事实、仍然未知的日期或行动，以及截止日期、依赖关系和原时间安排受到的当前影响。用户可以进行期间执行核对，也可以选择记不清或跳过；系统不得要求逐日、逐项追溯，也不展示需要补完的积压清单。

## 新入口建议

Agent 根据当前用户方案和当前时间推荐一个重新进入选项，同时保留继续原下一步行动、缩小后开始、改到具体时间、暂停用户方案和今天暂不恢复五个确定性选择。系统不要求用户先解释执行空档原因。模型不可用时，事实核对和五个选择仍然可用，只是不显示 Agent 推荐项。

只有用户确认新的入口后，系统才创建新的执行安排并恢复主动干预；涉及时间安排或用户方案变化时使用确定性变更确认。选择今天暂不恢复后结束当前流程，不继续追问。旧执行建议、通知和安排保持过期，不得因重新进入而复活。建议跨过用户本地自然日或其依赖的状态发生变化后必须重新生成。

## v0.1 邮件边界

v0.1 的邮件再触达只传达重新进入意图，并提示用户自行打开 PC 应用，不实现从邮件链接直接唤起本地应用、定位重新进入流程或传递认证信息。可点击邮件入口延后到网页客户端和常开服务器模式实现后再设计，并需要另行决定身份认证、链接有效期和跨设备状态边界。
