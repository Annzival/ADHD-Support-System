# 显式切换恢复上下文时保留旧执行结果未知

恢复时旧会话仍执行中且尚未到跟踪截止，用户可以选择按当前计划继续；只有用户明确确认切换并确认新会话所需的检查时间后，Core 才原子地结束旧会话的应用内跟踪、使旧检查点及相关待执行核对失效，并建立当前计划行动的新会话及首次检查点，始终只占用一个活动位置。旧会话记录退出原因为“用户选择切换”，实际结果保持未知，不记为完成、失败或暂停，不进入收尾，也不生成旧会话的执行结果证据或恢复包；取消确认、校验失败或保存失败时，该切换不改变旧状态。该决定补充 ADR-0046 的未知结果退出路径，不替代无回应到期或等待收尾的规则；记录用户切换事实不等于确认旧行动的执行结果。
