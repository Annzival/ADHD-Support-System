# 将建议锚定在业务上下文并只在首页汇总待决定项

每项有效智能体建议的权威入口位于它所关联的用户方案、下一步行动、日终复盘或重新进入流程中。应用不建立需要用户清空的全局建议收件箱。首页只提供“需要你决定”的待决定建议汇总，按当前执行、今天安排、用户方案和复盘分组，展示简要内容、影响范围和进入对应上下文的操作，不展示完整建议正文、未读数量或红点。

没有待决定建议时，首页隐藏整个汇总区域。已经查看但尚未决定的建议继续保留；查看不等于处理。设置了稍后处理时间的建议仍可在对应业务上下文中找到，但在恢复时间到达前不占据首页的主要位置。

已经过期、被取代、接受或不采用的建议退出首页汇总和普通业务界面，只保留在历史或审计入口中。应用内气泡、置顶小窗和系统通知必须直接定位到对应建议及其上下文，不能只打开首页要求用户再次寻找；邮件是否可用于某类建议仍受各场景的渠道规则约束。
