# v0.1 仅承诺 Windows 10 22H2 x64

v0.1 唯一承诺支持并完成桌面能力技术验收的运行环境是 Windows 10 22H2 x64。项目不主动阻止应用在 Windows 11 上运行，但 Windows 11 及其他操作系统不属于 v0.1 的测试和支持承诺；这一范围使托盘常驻、置顶小窗、开机启动、可交互通知和 Python 进程守护都有单一、可复现的验收环境。

## 影响

Windows 10 已结束常规支持，消费者扩展安全更新也将在 2026-10-13 结束，因此本决定只定义 v0.1 的验证环境，不构成长期平台承诺。完成 v0.1 闭环验证后，需要重新评估后续版本的目标操作系统。
