# 日终复盘先核对事实再提供有限分析

日终复盘在主窗口中先显示确定性执行摘要，包括当天计划的下一步行动、用户确认的完成或部分完成、暂停和改期、实际用时与原估时、仍处于未知状态的行动，以及当天执行安排调整。未知状态必须明确显示为未知，不能写成未执行。用户可以直接修正事实，并可以对任何复盘问题选择跳过或记不清；系统不要求用户逐项解释未完成原因。模型不可用时，用户仍可保存事实并完成日终复盘。

事实核对后，Agent 最多提供三项简短分析，每项明确区分基于哪些执行证据形成的观察、仍然缺少的信息，以及下一次可以保留或调整什么。Agent 不得作心理诊断，也不得用单日数据推断稳定人格或长期模式。

## 方案调整建议

估时校准、改期或其他用户方案变化以独立的方案调整建议卡片呈现，包含依据、影响范围和变更前后差异。完成日终复盘不表示用户接受这些建议；修改用户方案或当天执行安排前仍需确定性变更确认。

日终复盘只是方案调整建议的一个可能来源。方案审阅、阻碍支持、可行性分析、执行空档后的重新进入以及时间安排与干预策略冲突等其他上下文也可以产生同一类方案调整建议；该领域对象不得从属于日终复盘模块。

## 生命周期与渠道

日终复盘完成后，系统不再为其中每条建议单独发送气泡、系统通知或邮件。未决定且仍有效的建议保留在对应业务上下文和首页汇总中。模型不可用时，不在恢复后自动生成并主动推送迟到的分析；只有用户再次打开复盘或主动请求时才生成。补记日终复盘使用相同结构，但建议必须依据当前状态，不得重新激活过时安排。
