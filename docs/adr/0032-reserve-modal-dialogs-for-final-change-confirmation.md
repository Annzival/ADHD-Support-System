# 只将模态框用于用户主动发起后的最终变更确认

Agent 生成建议时不得自动打开模态框、切换当前界面或抢夺键盘焦点。系统主动产生的非阻塞建议默认使用气泡或弱提示入口；用户打开入口后，主窗口定位到相应的智能体建议卡片或上下文对话。置顶小窗、系统通知和邮件同样只提供入口，不承载完整建议或最终确认。

用户主动选择“现在有点难开始”“请求阻碍支持”等操作时，系统可以直接打开主窗口中的上下文对话，但不得使用覆盖全局的模态框。当前流程缺少继续所必需的信息时，在当前页面显示可退出并可保存现场的内联阻塞面板，不使用强制弹窗。

## 最终确认

只有用户已经选择“接受”或“修改后接受”，且建议即将修改用户方案或当天执行安排时，才允许显示变更确认模态框。该模态框由确定性界面生成，至少显示变更前后差异、影响范围、确认和取消操作；它不调用 LLM，不承载新的 Agent 对话，也不得在用户确认期间改变待应用内容。
