# 建议界面不抢夺焦点并保持完整键盘可达性

应用内气泡、后台生成的智能体建议和状态更新不得自动抢夺键盘焦点。用户主动打开气泡、系统通知或首页摘要后，应用激活主窗口、定位到对应建议，并将焦点放在建议标题而不是接受操作。建议卡片的阅读和操作顺序依次为建议内容、依据与未知信息、影响范围、接受、修改后接受、稍后处理和不采用。

所有操作都必须能够通过 Tab、Shift+Tab、Enter 和 Space 完成，不要求用户记忆快捷键。关闭建议、完成操作或取消后，焦点优先返回原触发控件；原控件已经消失时，返回对应业务上下文的标题，不重置到页面顶部。

## 变更确认

变更确认模态框将焦点限制在自身范围内，Esc 执行取消，默认焦点放在取消操作，关闭后将焦点返回发起确认的控件。按下 Enter 不得在没有明确导航到确认操作时意外应用修改。

## 非视觉状态与动态效果

后台建议使用非打断式的辅助技术提示，不强制朗读或连续播报。未查看、已过期和已被取代等状态必须提供文字标识，不能只依赖颜色、动画或图标。界面遵守操作系统的减少动态效果设置，建议注意请求不得使用闪烁或持续动画。

置顶小窗中的建议入口可以通过键盘打开主窗口，但完整建议处理仍在主窗口完成。以后可以增加可选快捷键，但任何快捷键都不能成为操作的唯一方式。
