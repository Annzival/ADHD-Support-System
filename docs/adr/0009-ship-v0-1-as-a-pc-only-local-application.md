# 将 v0.1 作为仅限 PC 本机的应用交付

v0.1 以单一 PC 应用交付，其中只有一个面向用户的桌面客户端，具有权威性的 Python 智能体核心默认运行在同一台 PC 上。智能体核心负责业务规则、Agent 行为、任务调度和 SQLite 数据持久化。Web/PWA、公网访问、移动客户端、多用户、多设备同步和远程部署均明确延后；这使首版保持 local-first，并避免在执行支持闭环得到验证前构建分布式同步系统。

## 演进路径

同一个智能体核心以后可以迁移到持续运行的自托管 Linux 服务器，使其他客户端或外发通知渠道能够随时连接。这是预留的架构演进方向，不属于 v0.1 范围。
