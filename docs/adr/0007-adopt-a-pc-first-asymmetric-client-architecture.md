# 采用 PC 优先的非对称客户端架构

当时决定以 Python 智能体核心（当时使用 Agent Service 这一名称）作为产品核心，以响应式 Web/PWA 作为跨设备客户端，并由 Wails v3 桌面宿主在 PC 上封装同一套前端，同时提供开机启动、系统托盘、原生通知和常驻或置顶窗口。原生移动客户端延后到执行闭环得到验证之后，以尽量复用前端并提供主动的 PC 支持，同时避免首版承担完整原生移动端的复杂度。

## 影响

截至 2026-08-10，Wails v3 仍是 beta 预发布软件，其发布说明称 API 已稳定，因此初始构建需要锁定确切版本，并将 Wails 专属集成隔离在桌面宿主内。持久调度仍由智能体核心负责：Wails 的定时通知在 macOS 上可以跨重启保留，但 Windows 和 Linux 的实现使用进程内计时器，宿主退出后会丢失待发送通知。
