# 日终复盘主动窗口结束后保留三天被动入口

用户可以启用日终复盘，并设置一个位于干预策略允许时段内的复盘窗口。只有当天发生过执行会话、存在尚未确认的原定工作，或发生过用户方案或执行安排调整时，系统才在窗口内主动提示至多一次；没有相关内容时不触发。PC 在窗口内重新上线时仍可提示，窗口结束后主动干预即失效，不进行后续追问或次日补发。

## 补记入口

窗口结束后 72 小时内，主界面保留一个纯被动的“补记近期复盘”入口，不使用系统通知、邮件、气泡、模态框、红点或未读数字。多个未复盘日期合并到同一入口，由用户自行选择日期，也可以忽略或永久跳过某一天；完成较晚日期的复盘不自动关闭更早日期的补记入口。

## 过期与建议

72 小时后入口消失，原始执行证据继续保留，未进行复盘不记为失败。补记复盘产生的方案调整建议必须以当前状态为依据，不得重新激活已经过时的执行安排。
