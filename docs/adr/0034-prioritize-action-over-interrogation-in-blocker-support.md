# 阻碍支持先提供行动而不要求完整解释

用户选择“现在有点难开始”或“请求阻碍支持”后，应用立即在主窗口打开对应上下文，不等待 LLM 返回才响应操作。界面始终提供改期、暂停并保存恢复包和今天不做等确定性退路；模型暂时不可用时，这些操作仍然可用。这类支持由用户主动触发，不再另外发送气泡、系统通知或邮件。

Agent 优先使用已有的下一步行动、预计时长、当前执行会话和恢复包生成一项可执行建议，不重复询问系统已经记录的信息。如果某项缺失信息会实质改变首项建议，Agent 在给出建议前最多询问一个低成本问题，优先提供二至四个具体选项，并允许用户选择记不清、不确定，或跳过并基于现有信息获得建议。系统不得要求用户先完整解释原因，也不得在首项建议前连续提问。

## 首项建议边界

首项建议必须足够小，并明确属于缩小当前下一步行动、调整当前执行方式、改到具体时间、暂停并保存恢复包或今天不继续之一。用户获得首项建议后，可以自行选择是否进入更深入的上下文对话。建议依赖的下一步行动或执行会话状态发生变化后，原建议按照 ADR-0030 标记为已被取代或已过期。
