# V-05 第二轮用户观察（方案 D）

> 来源：当前 prototype session 的用户回传。第一轮原始观察保留在同目录的 `用户观察.md`。

## 四项核对

用户确认下列四项均通过：

1. 不依赖系统通知也能从主窗口进入，并能区分上次执行上下文与当前计划；
2. 在“只错过计划开始”场景中，上一项路线只有“处理上一项”，没有“继续上次执行”；
3. 选择“按当前计划继续”后，上一项仍保持未知；
4. 从“暂不决定”后的被动入口重新进入时，只有一组恢复选择，没有重复面板。

## 补充反馈

> 分别“上次”与“当前”的确打开了对应上下文，但点击其中一个会关闭另一个上下文，因此这两个按钮更接近于“切换”，我希望呈现的效果是两个上下文可以同时完整呈现。

## 收敛记录

这项反馈只澄清方案 D 内部的展开语义，不增加新方案或新产品能力。prototype 已调整为两个独立的“展开 / 收起”入口：先展开一条，再展开另一条时保留前一条；只有用户作出实际执行选择后，才只显示所选上下文。

根据 Issue #7 的“两轮体验”退出条件，此调整不再开启第三轮用户走查；它会与对应的静态交互核验一并记录在结果文档中。
